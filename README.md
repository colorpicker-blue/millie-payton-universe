# Millie & Payton — interactief verhalenuniversum

Een doorlopende, kindvriendelijke bedtijdverhalenwereld voor **Millie (6)** en **Payton uit Ninja Kidz**, met een browserdashboard en een overdraagbare wereldbijbel.

## 🤖 Laat een nieuwe ChatGPT-chat een verhaal maken

Geef de chat deze openbare repository:
https://github.com/colorpicker-blue/millie-payton-universe

Gebruik bijvoorbeeld deze prompt:

> Lees eerst AGENTS.md, STORY_BIBLE.md, CANON.md, STORY_WORKFLOW.md en data/universe.json uit deze repository. Volg de regels voor het Millie & Payton-universum. Stel eerst drie verhaalideeën voor. Vertel daarna een interactief bedtijdverhaal met precies drie A/B/C-keuzes. Houd rekening met de bestaande canon. Geef na afloop de wijzigingen voor de wereldbijbel en werk de canon op GitHub bij als je schrijfrechten hebt.

**Belangrijk:** Alleen een GitHub-link vermelden is niet genoeg als de chat de bestanden niet daadwerkelijk kan ophalen. Gebruik een chat met GitHub-toegang of lever de bestanden mee. Een publieke repository betekent niet dat iedere chat automatisch GitHub-schrijfrechten heeft.

## 📚 Bestanden
- [AGENTS.md](AGENTS.md): instructies en leesvolgorde voor AI
- [STORY_BIBLE.md](STORY_BIBLE.md): vaste verhaalregels en personages
- [CANON.md](CANON.md): daadwerkelijk gevestigde gebeurtenissen
- [STORY_WORKFLOW.md](STORY_WORKFLOW.md): stapsgewijze interactie
- [data/universe.json](data/universe.json): machineleesbare canon
- [index.html](index.html): lokaal werkend ouderdashboard

## 🖥️ Dashboard
Open de website via GitHub Pages wanneer die ingeschakeld is:
https://colorpicker-blue.github.io/millie-payton-universe/

Of open `index.html` lokaal.

Het dashboard kan avonturen, keuzes, personages, locaties en verhaallijnen registreren. De invoer staat **alleen in de localStorage van de betreffende browser**. Het dashboard synchroniseert momenteel **niet** met de canonbestanden op GitHub of met andere apparaten. Gebruik JSON-export/import als back-up.

## 🔐 Privacy
Deze repository is publiek. Sla geen adres, school, foto's, contactgegevens of andere privégegevens van het kind op. De verhalen zijn fictie.

## 🔄 Continuïteit
Na een afgerond avontuur moeten `CANON.md` en `data/universe.json` gezamenlijk worden bijgewerkt. Als een AI-chat geen schrijfrechten heeft, moet die de voorgestelde canonwijzigingen tonen in plaats van te beweren dat ze opgeslagen zijn.
