# Millie & Payton — Avonturenuniversum

Een eenvoudig, lokaal ouderdashboard voor de doorlopende interactieve verhalen van **Millie (6 jaar)** en **Payton van Ninja Kidz**.

## Openen
Download de repository en open `index.html` in een moderne browser. Er zijn geen dependencies of installatie nodig.

## Functies
- Overzicht van avonturen, personages, locaties en verhaallijnen
- Drie verhaalkeuzes en gevolgen per avontuur vastleggen
- Chronologische tijdlijn
- Voorlopige kaartweergave van ontdekte locaties
- JSON-back-ups exporteren en importeren

## Belangrijk
Gegevens worden alleen opgeslagen in de `localStorage` van de browser. GitHub synchroniseert deze gegevens **niet**. Exporteer regelmatig een back-up. Er is nog geen automatische verbinding met ChatGPT-verhalen.

## Toekomst
Een geïllustreerde, klikbare wereldkaart en een kindvriendelijke verkenmodus kunnen op dezelfde gegevensstructuur voortbouwen.
